# Compiladores - Grupo 11

Este site reúne a documentação oficial do projeto da disciplina de Compiladores, com foco na construção completa de um compilador.

<div class="hero-panel" markdown>

## Objetivo do projeto

Desenvolver um compilador funcional cobrindo as principais etapas do processo de compilação:

1. Definir a linguagem de entrada (sintaxe e semântica).
2. Implementar a análise léxica.
3. Construir o analisador sintático.
4. Realizar a análise semântica.
5. Gerar código intermediário ou final.
